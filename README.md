# TCP-сервер для преобразования выражений в RPN

Многопроцессный TCP-сервер на C, который преобразует арифметические выражения из инфиксной записи в постфиксную (обратную польскую запись).

Тип многозадачности: многопроцессность, fork  
Транспортный протокол: TCP  
Прикладной протокол: преобразование арифметического выражения из инфиксной записи в постфиксную обратную польскую запись  

## Как это работает

Клиент отправляет выражение, сервер обрабатывает его и возвращает результат в постфиксной записи.

**Пример:**

Запрос:
```
2 + 3 * 4
```

Ответ:
```
2 3 4 * +
```
## Используемые технологии

- C
- TCP/IP
- Make
- Valgrind

## Сборка  

```bash
make all
```

## Запуск сервера

```bash
./server [опции]
```

Пример:

```bash
./server -a 127.0.0.1 -p 5555 -l ./server.log
```
  
## Запуск клиента  

```bash
./client [опции] выражение
```

Пример:
```bash
./client -a 127.0.0.1 -p 5555 "2 + 3 * 4"
```

Ответ:
```
2 3 4 * +
```

### Опции сервера  
```
-a ip          IPv4-адрес сервера
-p port        порт сервера
-l path        путь к лог-файлу
-w N           задержка обработки запроса на N секунд
-d             запуск в режиме демона
-h             справка
-v             версия
```

### Опции клиента  
```
-a ip          IPv4-адрес сервера
-p port        порт сервера
-h             справка
-v             версия
```

### Переменные окружения  
```
SERVER_ADDR       адрес сервера/клиента    
SERVER_PORT       порт сервера/клиента  
```

### Тестирование    

```bash
make test
```  

Цель test запускает сервер, отправляет несколько запросов клиентом, проверяет ошибочный запрос и несколько одновременных запросов.

### Проверка утечек памяти  
```
make valgrind
```

Для полноценной проверки сервера под valgrind сервер нужно запустить отдельно под valgrind, затем отправить запросы клиентом и завершить сервер сигналом SIGTERM.
