Прикладной протокол: преобразование арифметического выражения из инфиксной записи в постфиксную обратную польскую запись.

=== Сборка ===
make all

=== Запуск сервера ===
./lab3pnsN3246_server [опции]

Пример:
./lab3pnsN3246_server -a 127.0.0.1 -p 5555 -l ./lab3.log

=== Запуск клиента ===
./lab3pnsN3246_client [опции] выражение

Пример:
./lab3pnsN3246_client -a 127.0.0.1 -p 5555 "2 + 3 * 4"

Ответ:
2 3 4 * +

=== Опции сервера ===
-a ip          IPv4-адрес сервера
-p port        порт сервера
-l path        путь к лог-файлу
-w N           задержка обработки запроса на N секунд
-d             запуск в режиме демона
-h             справка
-v             версия

=== Опции клиента ===
-a ip          IPv4-адрес сервера
-p port        порт сервера
-h             справка
-v             версия

=== Переменные окружения ===
lab3ADDR       адрес сервера/клиента
lab3PORT       порт сервера/клиента
lab3LOGFILE    путь к лог-файлу сервера
lab3WAIT       задержка обработки запроса сервером
lab3DEBUG      включение отладочных сообщений

=== Тестирование ===
make test

Цель test запускает сервер, отправляет несколько запросов клиентом, проверяет ошибочный запрос и несколько одновременных запросов.

=== Valgrind ===
make valgrind

Для полноценной проверки сервера под valgrind сервер нужно запустить отдельно под valgrind, затем отправить запросы клиентом и завершить сервер сигналом SIGTERM.
